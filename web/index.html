Merge Warden Web Companion — Support & Troubleshooting

If the Merge Warden application is not loading, displays a blank screen, or fails to render, follow these troubleshooting steps:

Troubleshooting Steps

  1. Hard refresh your current page using Ctrl + Shift + R (or Cmd + Shift + R on Mac).
  2. Try opening the application in a different web browser (e.g., Chrome, Safari, Firefox, Edge).
  3. Try accessing the application in an Incognito or Private Browsing window.

Direct Support Contact
